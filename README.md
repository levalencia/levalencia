> **Solution:** A working agent control plane you can run, study, and extend — with 96% frontier mechanism parity.

**Technical Implementation**

- **Architecture** — SvelteKit frontend, multi-service Docker Compose, Azure deployment via Bicep
- **Validation** — Vitest + svelte-check, semantic versioning with automated git tagging

### 🧩 Agent God Mode — 2,400+ Skills for AI Agents
> **Problem:** Loading thousands of skills into an agent causes "Death by a Thousand Skills" — 30K+ tokens before you type anything, skyrocketing API costs, confused responses.
> **Solution:** Local RAG with just-in-time skill injection — search the vault, retrieve only what's needed, save 30K+ tokens per session.

**Technical Implementation**
- **Scale** — 2,400+ curated skills (Azure, ML, DevOps, agentic AI, and more)
- **Local Embeddings** — @xenova/transformers (CPU-only, no API keys required)
- **RAG Architecture** — isolated skill vault hidden from agent's default prompt
- **Just-in-Time Injection** — agent searches → top 3 matches → reads only relevant SKILL.md
- **Integration** — works with Claude Code, Codex, Cursor, Windsurf, and other AI coding agents

🔗 [github.com/levalencia/agent-god-mode](https://github.com/levalencia/agent-god-mode)

### 🎧 HarmoniqHub — AI-Powered Music Organization (macOS)
> **Problem:** DJs waste hours manually organizing playlists — inconsistent track ordering, no intelligent suggestions, no way to visualize energy flow across a set.
> **Solution:** AI-powered playlist generation with energy/key compatibility, automatic track ordering, and wave visualization.

**Technical Implementation**
- **AI Playlist Generation** — intelligent curation based on energy, key (Camelot wheel), and mood
- **CoreML Classification** — genre, mood, theme detection
- **Wave Visualization** — real-time audio waveform display for set planning
- **Acoustic Fingerprinting** — ShazamKit + Chromaprint for duplicate detection
- **Architecture** — SwiftUI, SwiftData, Clean Architecture

🔗 [github.com/levalencia/HarmoniqHub](https://github.com/levalencia/HarmoniqHub)
